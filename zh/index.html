常见问题

常见问题解答

关于 Google 地图好评链接转换、高清二维码打印及 NFC 写卡应用的常见解答

如何将 Google 地图链接转换为 5 星好评直达链接？

粘贴您的 Google 地图链接，或在“搜索商家”标签页中搜索店铺名称。Quick NFC 会在浏览器中直接提取地点 ID 并生成 5 星好评直达链接，免费且无需 API 密钥。

Android 应用支持哪些类型的 NFC 芯片与卡片？

Quick NFC Android 应用支持标准 NTAG 系列芯片（NTAG213、NTAG215、NTAG216），以及兼容的 NFC 贴纸、滴胶卡、钥匙扣和 PVC 卡片。

Wi-Fi NFC 卡片的制作与克隆是如何工作的？

在 Android 应用中输入 Wi-Fi 名称和密码（或直接扫描读取现有的 Wi-Fi 卡片），然后贴近空白 NFC 卡片即可完成写入，方便顾客一碰连网。

可以使用 PIN 码或永久只读锁保护 NFC 卡片吗？

可以。Android 应用支持为兼容的 NTAG 卡片设置 4 位 PIN 密码锁定与解锁，或开启不可逆的硬件永久只读锁定。

可以在网站上生成适合打印的 Google 评价二维码吗？

可以！在网页转换链接后点击“生成二维码”，即可下载清晰的高分辨率 PNG 图片，适合打印在桌面台卡、收银台贴纸、小票和包装上。

Quick NFC 真的无需账号和 API 密钥即可完全免费使用吗？

是的，Quick NFC 基于 MIT 许可 100% 免费开源。在浏览器中转换 Google 地图好评链接和生成二维码无需注册、订阅或 Google Cloud API 密钥。
